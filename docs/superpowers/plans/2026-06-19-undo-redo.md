# Undo/Redo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a frontend-owned, unified undo/redo history spanning the graph and layout domains, with navigation context restored on undo/redo for highlighting.

**Architecture:** A single `HistoryStore` owns one undo + one redo stack of typed `Action` objects. Graph actions replay inverse/forward **RPCs** (the server stays authoritative; it never learns "undo" exists). Layout actions restore `{before, after}` `WorkspaceState` **snapshots**. Each action carries a `NavContext` restored before the change is re-applied and highlighted. Recording happens at the store-method layer behind a `suspend` guard; executors replay via non-recording paths.

**Tech Stack:** Svelte 5 runes, TypeScript (strict), Vitest (`npm test` = `vitest run`), Playwright e2e via `window.goofi`, Python/pytest for the (gated) backend bits.

**Reference spec (committed):** `docs/superpowers/specs/2026-06-19-undo-redo-redesign-design.md`. The spec's **§3 executor table** is the authoritative per-kind recipe (pre-state, inverse RPC, forward RPC); tasks below cite it rather than duplicating it. The spec's **decision log** governs all behavior questions.

## Global Constraints

- **One undo entry per mutation primitive.** No time-window coalescing. Composite helpers (`instantiateNodes`, `cloneNodes`, `removeNodes`) record one entry per inner primitive.
- **Never auto-clear** the history on user actions. Loads are recorded as `load_patch` checkpoints. **The only hard reset** is a backend-session change (manager `instance_id` changes).
- **TDD Iron Law:** no production code without a failing test first. RED → verify-fail → minimal GREEN → verify-pass → commit. Tests verify behavior through store state, never "an RPC was recorded" (the `FakeControl` never auto-emits events — a test must `emit()` and assert resulting state).
- **TypeScript strict, no `any` in app code.**
- **Frontend is server-authoritative** (`graph.svelte.ts` mutations are RPC wrappers; state writes only in `_handle`). **Display names are reused** (`manager.py:336`); **`add_node(force_name=True)` raises `KeyError` on collision** (`manager.py:83`). `member_uid` is **deferred** (not in the `node_added` payload, not required in-session).
- **Layout actions use `workspace.restore()`** (assign state, no `reseedIds`/migration) — **never** the existing `hydrate()`.
- **Tracked layout ops:** split, close, resize, move (drop-on-panel / drop-on-tab-bar), setPanelType, link-node-to-panel, tab add/close/duplicate/rename/reorder. **Not tracked:** maximize, setActive, selectTab, internal setPanelState, enteredPath navigation.
- Commit messages end with: `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`.

```typescript
// api/control.ts — NEW exported structural interface; `class ControlClient implements Control`
export interface Control {
  call<T = unknown>(op: string, payload?: Record<string, unknown>): Promise<T>;
  on(fn: (ev: ControlEvent) => void): () => void;
  onConnect(fn: (c: boolean) => void): () => void;
}

// stores/history.svelte.ts
export type GraphStoreT = ReturnType<typeof import('./graph.svelte').graph>;
export type WorkspaceStoreT = ReturnType<typeof import('../workspace/workspace.svelte').workspace>;
export interface ExecutorDeps { control: Control; graph: GraphStoreT; workspace: WorkspaceStoreT; }
export interface Executor<A extends Action = Action> {
  forward(action: A, deps: ExecutorDeps): Promise<void>;
  inverse(action: A, deps: ExecutorDeps): Promise<void>;
}
export const executors: Record<string, Executor>; // = { ...graphExecutors, ...(layoutExecutors as Record<string, Executor>) }

// test/fakeControl.ts — implements Control; emit/recordedCalls are FakeControl-only test extensions
class FakeControl implements Control {
  call<T = unknown>(op: string, payload?: Record<string, unknown>): Promise<T>; // records; never auto-emits
  on(fn): () => void; onConnect(fn): () => void;
  emit(ev: ControlEvent): void;                       // synchronously fans out to on() listeners
  recordedCalls(): Array<{ op: string; payload: Record<string, unknown> }>;
}

// stores/graphExecutors.ts
export const graphExecutors: Record<string, Executor>;
// workspace/layoutExecutors.ts
export const layoutExecutors: Record<string, Executor<LayoutAction>>;
// workspace/navContext.ts
export function captureNavContext(): NavContext;
export function restoreNavContext(ctx: NavContext): Promise<void>;
// workspace/workspace.svelte.ts (new methods)
restore(state: WorkspaceState): void;                 // assign; NO reseedIds/migration; reset ephemeral active/maximized
panelsBoundTo(nodeName: string): Array<{ panelId: string; state: unknown }>;
// stores/graph.svelte.ts (new public method, so load_patch executor avoids private _replaceSnapshot)
async applyLoadCheckpoint(yaml: string): Promise<void>; // load_text(yaml); used by load_patch inverse/forward
```

**Selection note:** `selection().nodes(panelId)` / `edges(panelId)` are **methods returning `Set<string>`**. `captureNavContext` converts to arrays; `restoreNavContext` sets via the store's setter.
